INSTALLING

  1. Mac: open the .dmg and drag Meridian Terminal to Applications. The first time macOS says it "could not verify" the app (the build is not yet signed by Apple): click Done, then open System Settings > Privacy & Security, scroll down and click Open Anyway, then Open. Only needed once.
  2. Windows: run the installer. If SmartScreen appears, click More info > Run anyway.
  3. Linux: make the AppImage executable (chmod +x) and run it.
  4. The app tells you when a new version is out. Click UPDATE to download it.
